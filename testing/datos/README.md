# Datos del Avance 3

[avance-3.csv](avance-3.csv) contiene las lecturas numéricas transcritas del monitor serie y del dashboard en las capturas del 23 de noviembre de 2026. `orden_en_fuente` sigue el orden visible en cada captura y la columna horaria queda vacía para el monitor serie. Los horarios web corresponden a Santiago de Chile. Las fuentes se analizan por separado porque las capturas no identifican cada evento con el mismo ID en ambas interfaces.

Consulta el [informe de pruebas](../reportes/avance-3.md) y las [capturas originales](../evidencias/README.md).
